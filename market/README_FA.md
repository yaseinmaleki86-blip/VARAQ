# ورق — VARAQ v9.4 | مدیریت سفارش، پرداخت و ادغام کنترل‌شده

## افزوده‌های نسخه ۹.۴

- **زنجیره صحیح وضعیت سفارش:** فقط انتقال مجاز `جدید ← آماده‌سازی ← ارسال‌شده ← تحویل‌شده` (امکان پرش از جدید به ارسال نیز پس از شرایط پرداخت وجود دارد). سفارش‌های نهایی یا لغوشده به حالت‌های قبلی برنمی‌گردند.
- **کنترل پرداخت:** سفارش با روش هماهنگی پرداخت (`manual`) تا زمان تأیید واقعی مدیر قابل ارسال نیست؛ سفارش پرداخت‌شده بدون فرایند رسمی بازپرداخت قابل لغو نیست؛ سفارش لغوشده تأیید پرداخت نمی‌شود. `cod` صرفاً هنگام تحویل است و به‌عنوان رسید بانکی علامت نمی‌خورد.
- **رسید یکتا:** تکرار یک شماره پیگیری بین سفارش‌های مختلف رد می‌شود. این کنترل جایگزین اصالت‌سنجی بانکی نیست.
- **تجربه فروشنده و مشتری:** در پنل فروشنده فقط عملیات مجاز نمایش داده می‌شود؛ در حساب مشتری وضعیت تجمیعی فروشگاه‌ها و پرداخت خواناتر است؛ دکمه خرید کتاب ناموجود حذف شده است.
- **امنیت خروجی:** محافظت از CSV سفارش‌ها در برابر اجرای فرمول در Excel و مشابه؛ افزودن `Secure` به کوکی هنگام تنظیم صریح آدرس HTTPS معتبر.
- **ارتقا از ۹.۳:** ابزار نصب، حساب‌ها، سفارش‌ها، جلدها، PDFها و رسید ثبت ادغام قبلی نسخه نصب‌شده ۹.۳ را نیز به شکل کپی ایمن انتقال می‌دهد؛ `INSTALL_AND_RUN` نیز اکنون انتقال مجاور را انجام می‌دهد.

**وضعیت:** سورس کامل هسته فروشگاهی محلی برای آزمون و توسعه، همراه با انتقال اطلاعات نسخه‌های ۹.۱/۹.۲ و واردکردن *کاتالوگ* نسخه ۸.۶ از روی ZIP اصلی. این بسته **ادغام واقعی با فایل ۸.۶ را از پیش انجام نداده است**؛ آن ZIP در محیط تولید در دسترس نبود. برای استفاده عمومی و پرداخت واقعی آماده نیست.

## نصب ویندوز

۱. ZIP جدید را در یک پوشه استخراج کنید. Python 3.10 یا جدیدتر لازم است.
۲. برای **حفظ حساب‌ها، سفارش‌ها، کتاب‌ها و فایل‌های نسخه ۹.۱/۹.۲**، پوشه نصب قدیمی را دست‌نخورده و با نام `VARAQ_Store_v9_1`، `VARAQ_Store_v9_2` یا `VARAQ_Store_v9_3` در کنار پوشه `VARAQ_Store_v9_4` نگه دارید. حتماً ابتدا نسخه قبلی را متوقف کنید. برنامه به ترتیب نسخه ۹.۲ و سپس ۹.۱ را بررسی می‌کند. اگر دیتابیس جدید از قبل ساخته شده باشد، انتقال خودکار انجام نمی‌شود؛ دیتابیس‌های جداگانه را دستی روی هم کپی نکنید.
۳. فایل `VARAQ_Book_Market_v8.6_1000_Books_Covers_Persian_Summaries_Full_Source.zip` را کنار فایل `MERGE_AND_RUN.bat` بگذارید. اگر از نسخه‌های متعدد آن استفاده کرده‌اید، فقط **یک** ZIP واقعی را در محل جست‌وجو نگه دارید.
۴. `MERGE_AND_RUN.bat` را اجرا کنید. در صورت نبود حساب مدیر، برنامه نام کاربری و رمز قوی می‌خواهد. پس از ورود اطلاعات، سایت با آدرس `http://127.0.0.1:8765` اجرا می‌شود.
۵. در پنل مدیر، «گزارش ادغام و سلامت کتاب‌ها» را باز کنید. علاوه بر آمار، خروجی CSV و گزارش JSON نیز دارد.
۶. برای اجرای بعدی `INSTALL_AND_RUN.bat` و برای توقف `STOP_ALL.bat` را بزنید.

**توجه:** ابزار ZIP فقط کتاب‌ها، جلدها، خلاصه‌ها و چند مشخصه کتاب‌شناسی را به سیستم Python وارد می‌کند. حساب‌ها، سفارش‌ها، دسترسی فروشندگان، پرداخت‌ها، ساختار دیتابیس Node و ماژول‌های اختصاصی نسخه ۸.۶ وارد نمی‌شوند. این داده‌ها در ZIP قدیمی می‌مانند؛ پاک‌کردن فایل قدیمی توصیه نمی‌شود.

## ادغام دستی و بدون اجرای سایت

```shell
python MERGE_V86.py "PATH_TO_V86.zip"             # فقط بررسی، بدون تغییر
python MERGE_V86.py "PATH_TO_V86.zip" --apply     # اعمال پس از کنترل
python CATALOG_AUDIT.py                          # ممیزی داده‌های فعلی
python AUDIT_MERGE.py                            # کنترل شروط ادغام
```

### معیارهای پذیرش

- دست‌کم ۱۰۰۰ رکورد کتاب متمایز شناسایی شوند.
- تک‌تک کتاب‌های کشف‌شده جلد قابل شناسایی و معرفی متنی بیشتر از ۱۵ نویسه داشته باشند.
- دست‌کم ۱۰۰۰ **تصویر غیرتکراری** و ۱۰۰۰ **معرفی غیرتکراری** وجود داشته باشد. امضای فایل‌های تصویری بررسی می‌شود، اما **کیفیت هنری یا حق نشر با این کنترل تأیید نمی‌شود**.
- ZIP از نظر مسیرهای خروج از پوشه، فایل‌های پیوندی و میزان فشردگی مشکوک کنترل می‌شود. کد Node.js/JavaScript قدیمی اجرا نمی‌شود.
- قبل از نوشتن اطلاعات، از SQLite نسخه جدید پشتیبان با SHA-256 گرفته می‌شود. درج کتاب‌ها تراکنشی است و در شکست، جلدهای تازه نوشته‌شده نیز پاک می‌شوند.
- تاریخ ثبت ادغام، اثر انگشت فایل ZIP و آمار کامل در `data/last_merge_v86_report.json` نگهداری می‌شود. در اجرای خودکار بعدی، همان ZIP موفق دوباره ادغام و برای آن بکاپ تکراری ایجاد نمی‌شود.
- در کتاب‌های هم‌نام، شابک و مشخصات نویسنده برای جلوگیری از ادغام اشتباه چاپ‌ها لحاظ می‌شود. قیمت، موجودی و معرفی کتابی که قبلاً دستی ویرایش شده، بازنویسی نمی‌شود.
