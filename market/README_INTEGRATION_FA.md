# ورق ۹.۵ — بسته کامل فایل‌ها و ادغام کاتالوگ واقعی

- سایت مرجع اصلی با Node.js از v8.6 **بدون حذف فایل‌های قبلی** در پوشه `varaq` باقی مانده است. آدرس محلی: `http://127.0.0.1:3030`.
- هسته فروشگاهی Python برگرفته از v9.4 در پوشه `market` قرار دارد. آدرس محلی: `http://127.0.0.1:8765`.
- **کاتالوگ واقعی ۱۰۰۰ کتاب از `data/books.json` و `data/generated_catalog_v86.json` در دیتابیس SQLite فروشگاهی پیشاپیش ادغام شده است**؛ شامل ۱۰۰۰ تصویر مفهومی اصلی، معرفی فارسی و تصویر بندانگشتی موجود در همان مسیرهای نسخه ۸.۶. تصاویر کپی نشده‌اند تا حجم فایل زیاد نشود.
- دو متن تکراری درباره The Stranger هارلن کوبن و The Lost World مایکل کرایتون در هنگام ورود با معرفی‌های تحریریه جدید اصلاح شده‌اند؛ متن‌های اصلی ۸.۶ دست‌نخورده‌اند.
- قیمت و موجودی فاقد منبع **صفر و ناموجود** هستند. هر فروشنده باید پیش از فروش، قیمت/موجودی واقعی ثبت کند؛ این جلدها «تصویر مفهومی» هستند نه جلد واقعی ناشر.
- برای اجرای هر دو سایت در ویندوز از `market/START_INTEGRATED_WINDOWS.bat` و برای توقف از `market/STOP_INTEGRATED_WINDOWS.bat` استفاده کنید. Node.js >=22.13 و Python >=3.10 لازم‌اند. ابتدا از شما ساخت حساب مدیر مستقل فروشگاه درخواست می‌شود؛ رمز پیش‌فرض وجود ندارد.
- برای کنترل کاتالوگ: `python market/VERIFY_INTEGRATED.py`.
- حقوق فروش PDF و اتصال درگاه پرداخت فروشنده **تأیید نشده/غیرفعال** است.

## محدودیت مهم
این نسخه **تجمیع واقعی سورس و رسانه در یک فایل ZIP و ادغام واقعی بانک ۱۰۰۰ کتاب با هسته فروشگاهی** است، ولی دو سامانه هنوز دیتابیس، نشست، کاربران و سفارش‌های مشترک ندارند. امکانات اختصاصی Node به Python منتقل نشده است. بنابراین «یک وب‌اپلیکیشن با یک ورود و یک پنل واحد» هنوز به‌طور کامل تحقق نیافته و نباید این بسته را آماده انتشار عمومی تلقی کرد.

فایل `RELEASE_MANIFEST.json` داخل پوشه اصلی به نسخه ۸.۶ مربوط است؛ فایل‌ها و کدهای جدید ۹.۵ به گزارش جداگانه خود نیاز دارند.

## بروزرسانی ۹.۶ — استفاده از یک آدرس برای هر دو بخش

**راه‌اندازی پیشنهادی:** فایل `varaq/START_UNIFIED_WINDOWS.bat` را اجرا کنید؛ نه فایل‌های قدیمی `START_INTEGRATED_WINDOWS.bat` که دو آدرس جداگانه باز می‌کنند.

- مرجع و اطلاعات کتاب: `http://127.0.0.1:3030/`
- خرید، سبد، سفارش و مدیریت فروش جدید: `http://127.0.0.1:3030/market/`
- مدیریت مرکزی قدیمی: `/panel` و مدیریت فروش جدید پس از ورود: `/market/admin`

مدیر و فروشنده‌ با مجوز کامل مدیریتی از ورود امن پنل اصلی استفاده می‌کنند و برای ورود به بخش فروش جدید رمز جداگانه وارد نمی‌کنند. مشتریان از `/market/register` ثبت‌نام می‌کنند. دفترهای سفارش و کاربریِ مشتریان هنوز بین Node و Python یکی نشده‌اند؛ برای فروش و حسابداری واقعی از این نسخه استفاده نکنید.

برای جزئیات و موارد اجرا نشده، `docs/CHANGELOG_9.6_FA.md` را بخوانید.
