# گزارش تست نسخه ۴.۱

- `npm test`: تعداد ۱۳۵ آزمون شناسایی‌شده؛ ۱۳۴ موفق، صفر شکست، یک آزمون تاریخی اجرا‌نشده.
- تست‌های جدید: تشخیص وضعیت آمادگی و تعارض مجوز، امنیت CSV، نمایش شفاف اطلاعات کتاب برای بازدیدکننده، مجوز نقش مدیریت و ممنوعیت دسترسی فروشنده.
- آزمون عملی ارتقا: دیتابیس ۴.۰ با ۲۰۰ عنوان و ۱۲۸ رکورد شناسنامه/منبع، یک حساب مدیر و یک فروشگاه به کد ۴.۱ منتقل شد؛ متن ویرایش‌شده قبلی حفظ شد. `PRAGMA integrity_check=ok` و `PRAGMA foreign_key_check` بدون خطا.
- داده پایه آزمایش: ۷۱ عنوان دارای حداقل معیار فنی سئو، ۱۱۴ عنوان بدون نویسنده، ۱۲۹ عنوان فاقد منبع چاپ، ۲۰۰ عنوان فاقد جلد دارای حق استفاده ثبت‌شده؛ صفر نامزد کامل بررسی انسانی. این نتایج صرفاً مختص داده آغازین آزمون هستند و می‌توانند با دیتابیس کاربر متفاوت باشند.
- آزمایش مرورگر واقعی روی موبایل/دسکتاپ و انتشار روی دامنه HTTPS واقعی انجام نشده؛ بنابراین این‌ها پیش‌نیاز انتشار باقی می‌مانند.
