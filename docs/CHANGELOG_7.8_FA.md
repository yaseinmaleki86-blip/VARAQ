# ورق ۷.۸ — راه‌اندازی مطمئن ویندوز و سفارش‌های نمونه در موبایل

## موارد بهبود یافته

۱. `START_WINDOWS.bat` دیگر پس از یک تأخیر ثابت مرورگر را باز نمی‌کند. ابتدا Node.js و معتبر بودن پورت بررسی می‌شوند و فقط پس از پاسخ موفق `/health` از سرور **همین نسخه**، مرورگر باز خواهد شد. اگر پورت اشغال باشد، برنامه دیگری به اشتباه به‌عنوان ورق باز نمی‌شود. `RUN_SERVER_WINDOWS.bat` پنجره مستقل سرور و پیام خطا را نگه می‌دارد. راه‌انداز با HOST=127.0.0.1 فقط برای لوکال است؛ برای سرور عمومی از راهنمای استقرار استفاده کنید.

۲. فهرست سفارش‌های آزمایشی فروشنده در نمایش موبایل به کارت‌های خوانا تبدیل شده است. در دسکتاپ جدول کامل قبلی باقی می‌ماند. جزئیات، مبلغ نمونه، وضعیت چک‌لیست و لینک اقدام با سطح لمس مناسب نمایش داده می‌شوند. سفارش‌ها همچنان کاملاً آزمایشی‌اند.

۳. `OPERATIONS_QA_WINDOWS.bat` با `tools/operations-check.js` آزمونی غیرمخرب اجرا می‌کند. ابزار یک سرور و دیتابیس موقت ایجاد می‌کند، دسترسی مدیر مرکزی و فروشنده، جداسازی اطلاعات فروشگاه‌ها، محافظت CSV و مسدودماندن فایل PDF خصوصی و پرداخت را می‌سنجد؛ در پایان فایل‌های موقت را پاک می‌کند. این ابزار روی اطلاعات نصب اصلی تغییر نمی‌دهد.

۴. `tools/startup-guard.js` پورت اشغال‌شده یا سرویس غیرمنتظره را تشخیص می‌دهد، در هنگام شروع سلامت `version=7.8.0` و `payment_enabled=false` را تأیید می‌کند و تا تأیید، مرورگر را باز نمی‌کند.

## محدودیت‌ها و هشدارها

- اجرای واقعی `*.bat` روی Windows در این محیط تأیید نشده؛ صرفاً منطق Node و متن فایل‌های راه‌انداز آزمون شده است. فایل‌های Windows را روی رایانه واقعی امتحان کنید.
- بررسی آفلاین Chromium یا آزمون خودکار HTTP جای تست لمسی روی گوشی واقعی را نمی‌گیرد.
- درگاه، پرداخت، رزرو موجودی، ارسال واقعی و تحویل پولی PDF همچنان **غیرفعال** هستند. نتایج QA مجوز انتشار تجاری نیست.
- پیش از ارتقا: ابتدا `BACKUP_WINDOWS.bat`، سپس `STOP_ALL.bat`، حفظ کامل `storage` و فایل‌های رسانه، بعد جایگزینی سورس. اگر مسیر داده با `DATA_DIR` تعریف شده، همان مسیر را حفظ کنید.

## آزمون‌های نگه‌داری

```sh
node --test tests/phase78.test.js
node tools/operations-check.js
node tools/mobile-check.js
node verify-release.js
```

فایل `OPERATIONS_QA_WINDOWS.bat` و آزمون‌های مخصوص نسخه ۷.۸ فقط برای بررسی جریان آزمایشی ساخته شده‌اند.
