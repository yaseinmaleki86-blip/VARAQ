# تغییرات VARAQ 2.2

- اضافه‌شدن پنل خصوصی جست‌وجوی اینترنتی تصویر جلد مبتنی بر شابک و ناشر.
- ایجاد جدول مستقل پیشنهادهای اینترنتی (بدون انتشار خودکار).
- بررسی URLهای HTTPS و رد نشانی‌های محلی و پرخطر، بدون دانلود سروری تصاویر.
- خروجی CSV برای جست‌وجوی ۲۹ شناسنامه منبع‌دار موجود.
- حفظ تفکیک مالک مرکزی و فروشندگان، و غیرفعال بودن پرداخت.
- هیچ عکس جدیدی بدون تعیین و تأیید حق استفاده تجاری روی صفحه عمومی منتشر نشده است.
