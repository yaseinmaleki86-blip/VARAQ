# ورق (VARAQ) نسخه ۳.۸ — سئو، سرعت و آمادگی فنی

**وب‌سایت کامل، مبتنی بر ۳.۷.** پرداخت آنلاین و ارسال واقعی غیرفعال باقی مانده است. این نسخه از نظر سئو و سرعت بهبود پیدا کرده اما **مجوز انتشار، تأیید متون، تبلیغات، ایندکس گوگل یا آمادگی فروش واقعی را تضمین نمی‌کند**.

## چه تغییر کرده؟

1. در `head` صفحات، اطلاعات Open Graph شامل `og:locale=fa_IR`، عنوان، توضیح، URL قانونی (canonical) و نوع صفحه ایجاد می‌شود. هیچ عکس ناشرِ بدون مجوز برای متادیتای اشتراک‌گذاری تازه منتشر نمی‌شود. داده‌ها قبل از قرارگیری در HTML escape می‌شوند.
2. برای صفحه اصلی داده ساختاریافته `WebSite` و `Organization` و برای صفحات کتاب و دسته‌بندی، `BreadcrumbList` مطابق Schema.org اضافه شد. داده `Book` نسخه قبلی حفظ شده است؛ اطلاعات نویسنده، شابک و تصویر فاقد مدرک اختراع نمی‌شوند.
3. **کنترل کیفیت ایندکس:** در حالت `PUBLIC_URL`، صفحه کتاب فاقد نویسنده یا فاقد چاپ مستند/تأییدشده، همچنان برای بازدیدکننده قابل مشاهده است ولی `noindex,follow` می‌گیرد و در سایت‌مپ عمومی کتاب‌ها درج نمی‌شود. در سایت‌مپ عمومی پروفایل نویسنده/ناشر و موضوعات کم‌اطلاعات نیز کنار گذاشته می‌شوند. این رفتار فقط روی ربات‌ها اثر می‌گذارد، نه نمایش کتاب در سایت یا سبد نمایشی. در حالت توسعه محلی، همان سیاست `noindex,nofollow` تمام صفحات حفظ شده است.
4. **کش دارایی‌های ثابت:** HTML حالا فایل‌های CSS/JS را با نام حاوی هش محتوا درخواست می‌کند (`/assets/style.<hash>.css` و `/assets/app.<hash>.js`)، با کش یک‌ساله `immutable` و پاسخ‌های ETag/304. آدرس‌های قدیمی `/assets/style.css` و `/assets/app.js` نیز با کش کوتاه‌تر و بدون حذف سازگاری کار می‌کنند.
5. **فشرده‌سازی پاسخ‌های عمومی:** صفحات فهرست، خانه و تعدادی صفحات اطلاعاتی برای بازدیدکننده بدون نشست/کوکی و در صورت درخواست مرورگر با gzip ارائه می‌شوند. صفحات سبد، دریافت سفارش محرمانه، صفحه کتاب با توکن نظر و تمام درخواست‌های دارای کوکی از این مسیر کنار گذاشته شده‌اند.
6. **کاهش سربار:** دستور SQLite مورد استفاده کارت‌های کتاب یک بار آماده می‌شود. روند قیمت‌گذاری و تخفیف‌ها تغییر نکرده است.
7. گزارش ممیزی خواندنی `npm run seo:audit` اضافه شد؛ `node preflight.js` اکنون تعداد کتاب‌های واجد شرایط ورود به سایت‌مپ را نیز اعلام می‌کند. تمام داده‌ها در `storage` حفظ می‌شوند؛ هیچ مهاجرت دیتابیسی جدید ضروری نیست.

## ممیزی بانک اولیه (در نصب آزمایشی)

- کتاب: **۲۰۰** عنوان
- نویسنده ثبت‌شده: **۸۶** عنوان
- توضیحات با حداقل ۱۲۰ کاراکتر: **۰** عنوان
- واجد شرط حداقلی سایت‌مپ کتاب: **۷۱** عنوان
- نیازمند تکمیل منبع و/یا نویسنده برای سایت‌مپ: **۱۲۹** عنوان
- منابع چاپ با حق استفاده تأییدشده برای تصویر: **۰** مورد در جدول `edition_sources`

**توجه:** حتی ۷۱ صفحه واجد شرط سایت‌مپ، الزاماً محتوای جامع یا مورد تأیید حقوقی ندارند؛ این شمارش فقط یک حداقل فنی است. نام کتاب/نویسنده تنها به معنی حق انتشار تصویر جلد نیست. باید پیش از انتشار عمومی داده‌های واقعی، حقوق عکس‌ها و دستورالعمل‌های محلی/قانونی کسب‌وکار بررسی شوند.

## نصب و ارتقا از ۳.۷

1. نسخه پشتیبان از `storage` و تصاویر و دیتابیس بگیرید و سرور را متوقف کنید.
2. فایل‌های برنامه را جایگزین کنید ولی پوشه **`storage` قبلی را دست‌نخورده حفظ کنید**.
3. در ویندوز `START_WINDOWS.bat` را اجرا کنید (Node.js ۲۴ پیشنهاد می‌شود؛ حداقل ۲۲.۱۳). نیازی به `npm install` نیست.
4. صحت `/health` با `version: 3.8.0` و `payment_enabled:false` را ببینید.
5. `npm test`، `npm run seo:audit` و `node preflight.js` را اجرا کنید؛ پیش از راه‌اندازی روی اینترنت، با موبایل/دسکتاپ در مرورگرهای واقعی و URL HTTPS نهایی هم بررسی نمایید.

## محدودیت‌ها و خطرات باز

- اعتبارسنجی حقوق کپی‌رایت عکس‌ها، تأیید اطلاعات شابک، تکمیل متون ۲۰۰ کتاب و درگاه فروشنده هنوز لازم است.
- گوگل ایندکس‌ شدن، رتبه، Core Web Vitals و عملکرد تحت بار واقعی فقط روی دامنه/سرور نهایی قابل سنجش هستند؛ تست فعلی جای آن‌ها را نمی‌گیرد.
- فونت Vazirmatn هنوز از Google Fonts بارگیری می‌شود؛ بارگیری آفلاین بدون فونت نصب‌شده ممکن است با فونت جایگزین نمایش داده شود.
- تست تعاملی مرورگرهای واقعی و موبایل هنوز کامل نشده و نسخه ۳.۹ باید آن را همراه با بررسی امنیت، لاگ و استقرار انجام دهد.
