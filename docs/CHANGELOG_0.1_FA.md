# گزارش فاز 01 — نسخه 0.1.0

- هسته اجرایی Node.js بدون نصب وابستگی npm.
- پایگاه داده رابطه‌ای SQLite + WAL و محدودیت‌های صحت داده.
- ورود مدیر و فروشنده، رمز scrypt، نشست مبتنی بر توکن hash، CSRF و محدودیت تلاش ورود.
- جداسازی فروشگاه‌ها در پنل موجودی، ثبت لاگ مدیریتی.
- کاتالوگ ۲۰۰ عنوان، جست‌وجو/دسته‌بندی/صفحه اختصاصی/نقشه سایت.
- قالب حرفه‌ای RTL برای موبایل و دسکتاپ.
- ساخت فروشگاه و حساب فروشنده از پنل مرکزی.
- افزودن قیمت/موجودی واقعی فقط توسط حساب مجاز و در چارچوب فروشگاه.
- سبد انتخاب محلی بدون سفارش یا پرداخت واقعی.
- اسکریپت پشتیبان SQLite و راه‌اندازی ویندوز.
- تست یکپارچه: نصب اولیه، CSRF، ایزوله‌بودن فروشنده، ثبت موجودی، SEO، پرداخت خاموش.
- بررسی رندر در عرض دسکتاپ ۱۴۴۰ و موبایل ۳۹۰ پیکسل؛ بدون اسکرول افقی در صفحه اصلی و کاتالوگ.

**محدودیت مهم:** این گزارش ادعای تکمیل ۱۲ فاز نیست؛ فقط اسکلت واقعی فاز نخست و امکانات فوق اجرا شده‌اند. برای انتشار عمومی پرداخت‌دار هنوز فازهای بعدی و تأیید حقوقی ضروری‌اند.
