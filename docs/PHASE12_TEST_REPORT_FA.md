# گزارش آزمون فاز ۱۲ — VARAQ 1.2

## آزمون‌های خودکار

- دستور: `npm test` روی Node.js 22.16.0
- **۳۵ آزمون موفق، ۰ شکست، ۰ عبور از تست (skip)**.
- آزمون‌های موجود نسخه‌های 0.1 تا 1.1 حفظ شدند و آزمون‌های 1.2 نیز اضافه شدند: بکاپ کامل و manifest، بررسی هش فایل، بازیابی در مسیر جدید، رد بازنویسی مسیر موجود، جلوگیری از بازیابی بکاپ دستکاری‌شده، حفظ وضعیت فروشگاه و رسانه خصوصی، محافظت ایندکس صفحات خصوصی، هدرهای امنیتی، غیرفعال‌بودن پرداخت، ممیزی محتوای فقط‌خواندنی و پاسخ HEAD.

## رندر ایستای صفحات

- صفحه خانه، کتابخانه و کمک‌درسی در نماهای ۱۴۴۰ و ۳۹۰ پیکسل.
- هر شش صفحه بدون بیرون‌زدگی افقی. اسکرین‌شات صفحه خانه دسکتاپ و موبایل جداگانه ارائه شده است.
- برای رندر، HTML واقعی سرور و CSS از برنامه گرفته شد و از `page.set_content` در Chromium استفاده شد؛ مرورگر این محیط پیمایش URL لوکال را مسدود می‌کند. در نتیجه **تست کلیک و تعامل زنده با سرور تأیید نشده است.**

## نمونه سنجش سرعت محلی

- ۶۰ درخواست HTTP GET، هم‌زمانی ۶، ۰ خطا، زمان کل ۰٫۱۳ ثانیه، میانه ۸ میلی‌ثانیه، صدک ۹۵ برابر ۳۴ میلی‌ثانیه در محیط توسعه فعلی.
- این ارقام فقط نشانه عملکرد محیط تست هستند؛ برای ظرفیت تولیدی نیازمند تست بار تحت شبکه، هاست و داده‌های واقعی هستیم.

## کیفیت بانک محتوایی نصب تازه

- ۲۰۰ عنوان؛ ۱۴۷ عنوان بدون نویسنده، ۲۰۰ عنوان بدون ناشر و شرح معرفی، ۰ تصویر جلد، ۰ چاپ تأییدشده و ۰ منبع آموزشی منتشرشده.
- شابک برای عنوان‌های عمومی خالی است و باید در سطح چاپ/ویرایش معتبر درج شود؛ بدون استناد، شابک ساختگی تولید نشده.
- هیچ پرداخت واقعی در این نسخه امکان‌پذیر نیست.

## مانع‌های انتشار عمومی

- تکمیل محتوای معتبر و مجوز استفاده از جلدها؛ تأیید فروشگاه واقعی و مدارک/مجوزهایش.
- HTTPS و پیکربندی محیط تولیدی، تغییر رمز اولیه، متن حقوقی و اطلاعات تماس نهایی.
- مرورگر و تست بار روی هاست واقعی، ممیزی امنیتی مستقل و طرح عملیاتی نگهداری بکاپ در فضای خارج از سرور.

به این دلایل، این نسخه برای توسعه و ارزیابی محلی آماده است؛ **نه برای اعلام فروش و پرداخت عمومی**.
