# گزارش آزمون فاز چهارم — VARAQ 0.4

- اجرای `npm test` بر پایه Node.js 22.16 در محیط توسعه: **۸ تست، ۸ موفق، ۰ ناموفق**.
- آزمون‌های نسخه‌های 0.2 و 0.3 از جمله مدیریت حساب، چاپ، مجوز دسترسی فروشنده، CSV، جلد و ارتقای پایگاه داده دوباره اجرا شدند.
- آزمون‌های جدید شامل ثبت نظر معتبر/نامعتبر، جلوگیری از نمایش نظرهای تأییدنشده، تأیید توسط مدیر، رد دسترسی بدون ورود، escape داده‌های HTML، محدودسازی مقدماتی ارسال، پیش‌نویس و انتشار نقد، تطبیق نسخه‌های چاپی و مهاجرت بدون حذف اطلاعات است.
- مرورگر Chromium برای تصویرسازی و اندازه‌گیری CSS با HTML و CSS همان نسخه استفاده شد. بازکردن مستقیم سرور محلی از Chromium این محیط محدود شده بود؛ بنابراین این مرحله یک **بازرسی رندر ایستا** است و نه تست کامل تعامل در مرورگر.
- بررسی عرض صفحه: دسکتاپ ۱۴۴۰/۱۴۴۰ و موبایل ۳۹۰/۳۹۰ پیکسل، بدون بیرون‌زدگی افقی در صفحه جزئیات کتاب.
- آزمون بار، دسترس‌پذیری خودکار، پشتیبان‌گیری هنگام نوشتن همزمان و استقرار عمومی هنوز انجام نشده‌اند.
