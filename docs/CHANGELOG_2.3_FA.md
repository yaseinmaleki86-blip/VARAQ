# ورق — نسخه ۲.۳ | تکمیل اطلاعات چاپ و کنترل حقوق جلد واقعی

- هفت رکورد مستند جدید برای پنج عنوان: «صد سال تنهایی» (۲ ترجمه)، «بلندی‌های بادگیر»، «جین ایر»، «آنا کارنینا» و «جنگ و صلح» (۲ رکورد مستقل). منبع دقیق هر رکورد در فایل داده ثبت شده است.
- داده‌ها براساس شابک ثبت می‌شوند، نه فقط نام کتاب؛ تفاوت صفحه و چاپ باید قبل از فروش با نمونه فیزیکی تطبیق داده شود.
- مسیر `/panel/cover-research` اکنون مدرک تطبیق شابک و مدرک حقوق انتشار را نیز ثبت می‌کند. تایید نهایی بدون این دو مورد مجاز نیست.
- وضعیت «بررسی‌شده؛ آماده بارگذاری» به معنی انتشار خودکار نیست. عکس فقط از مسیر کنترل‌شده بارگذاری می‌شود.
- خروجی `/panel/cover-rights.csv` فقط برای مدیر مرکزی قابل دریافت است.
- هیچ جلد اینترنتی جدید بدون اجازه استفاده وارد صفحات عمومی نشده است. پرداخت آنلاین فعال نشده است.
- ارتقا: بکاپ کامل، توقف سرور، جایگزینی فایل‌های برنامه و حفظ پوشه `storage`.

- ۷۳ تست مستقل با نتیجه موفق. تست بار عمومی و بررسی تعاملی نهایی روی مرورگر مقصد انجام نشده است.
