# ورق ۷.۷ — بهبود واقعی کارت‌ها در گوشی و آزمون چیدمان

## اصلاحات
- در نمایشگرهای ۳۲۰ تا ۴۳۰ پیکسل، فهرست کتاب‌ها از دو ستون فشرده به کارت‌های افقی و خواناتر تبدیل می‌شود. تصویر در کنار عنوان و دکمه‌ها قرار می‌گیرد، نه بالای یک کارت بسیار بلند.
- در عرض ۳۴۰ پیکسل و کمتر، میانبرها زیر هم قرار می‌گیرند تا هرکدام فضای لمس کافی داشته باشند.
- متن عنوان، نویسنده، قیمت و وضعیت نسخه برای نمایشگرهای کوچک تنظیم شده است. کلیدهای اصلی حداقل ۴۴ پیکسل ارتفاع دارند.
- برچسب‌های ناوبری پایین روی گوشی‌های کوچک می‌توانند در دو خط نمایش داده شوند؛ صفحه نباید پیمایش افقی ناخواسته داشته باشد.
- «MOBILE_QA_WINDOWS.bat» همچنان بررسی HTTP و محرمانگی PDF را انجام می‌دهد؛ ابزار اختیاری `tools/mobile-layout-audit.py` مرورگر آفلاین را با عرض‌های ۳۲۰، ۳۹۰، ۴۳۰، ۷۶۸ و ۱۲۸۰ برای پنج مسیر عمومی بررسی می‌کند.

## محدودیت‌ها و انتشار
- آزمون آفلاین Chromium جای آزمایش تعاملی گوشی، Safari یا استقرار HTTPS واقعی نیست.
- برای اجرای ابزار اختیاری چیدمان: Python 3 و Playwright نصب‌شده با Chromium لازم است. این کتابخانه در بسته نصب اصلی قرار نمی‌گیرد و سایت به آن وابسته نیست.
- درگاه پرداخت واقعی، ارسال سفارش و دانلود پولی PDF فعال نشده‌اند.
- اطلاعات چاپ‌ها، عکس‌های مفهومی، متن‌های ویرایش‌شده و پوشه `storage` حفظ می‌شوند. نصب جدید را بدون حذف اطلاعات قدیمی جایگزین کنید؛ پیش از ارتقا بکاپ بگیرید.
