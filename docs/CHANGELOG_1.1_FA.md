# تغییرات نسخه 1.1 — منابع آموزشی و کنترل انتشار

**مبنا:** نسخه 1.0؛ بدون مهاجرت مخرب به پایگاه داده.

1. `lib/education-batch.js`: تجزیه CSV سازگار با علامت نقل‌قول و UTF-8 BOM، سقف ۲۵۰ ردیف، پیش‌نمایش ردیف‌ها و خطاها، تطبیق `book_id` با بانک واقعی، جلوگیری از تکرار، تراکنش گروهی و ثبت پیش‌نویس اجباری.
2. `lib/education-compare.js`: انتخاب معتبر دو یا سه شناسه یکتا و دریافت فراداده فقط از رکوردهای منتشرشده؛ پارامترسازی SQL.
3. `server.js`: صفحه اختصاصی CSV، دانلود نمونه و راهنمای کدها، دو مرحله پیش‌نمایش/ثبت، ثبت رویداد حسابرسی و پیاده‌سازی صفحه مقایسه. فقط مدیر YM مجاز است.
4. `public/app.js`: خواندن محلی فایل CSV و نمایش در فرم برای بررسی، بدون آپلود مستقیم یا ذخیره ناخواسته.
5. `public/style.css`: انتخاب کتاب برای مقایسه و جدول ریسپانسیو در دسکتاپ و موبایل.
6. داده‌های دیگر فروشندگان، سفارش‌های DEMO، حساب‌ها و تنظیمات کارمزد قبلی بدون تغییر باقی می‌مانند. پرداخت واقعی همچنان غیرفعال است.

**محدودیت مهم:** ورود گروهی کتاب جدید نمی‌سازد و کتاب آموزشی موجود را بازنویسی نمی‌کند. اگر نیاز به افزودن خود عنوان جدید است، ابتدا از پنل کتاب یا CSV عمومی استفاده شود؛ سپس فراداده با این ابزار اتصال یابد. انتشار پس از راستی‌آزمایی دستی انجام می‌شود.
