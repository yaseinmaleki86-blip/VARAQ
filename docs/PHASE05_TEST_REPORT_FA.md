# VARAQ 0.5 — گزارش آزمون‌ها

- اجرای `npm test`: ۱۰ آزمون، ۱۰ موفق، ۰ ناموفق.
- شامل تمام آزمون‌های گذشته فازهای ۱ تا ۴ به‌همراه دو آزمون انتها-به-انتهای فاز ۵.
- ساخت فروشگاه جدید حتی با درخواست `active=1`، تا تأیید اولیه غیرفعال می‌ماند.
- مدیر فروشگاه نمی‌تواند پرونده خودش را تأیید کند.
- نبود پروانه کسب یا تأیید دستی، مانع تأیید داخلی پرونده می‌شود.
- مدرک بارگذاری‌شده بدون نشست معتبر دانلود نمی‌شود.
- نقش موجودی فقط در فروشگاه خود امکان ویرایش دارد؛ نقش مشاهده‌گر حق ویرایش هیچ موجودی‌ای را ندارد.
- غیرفعال‌سازی کارمند، نشست فعلی او را باطل و ورود دوباره را متوقف می‌کند.
- راه‌اندازی با SQLite قبلی حساب‌ها، قیمت‌ها و موجودی قدیمی را حفظ می‌کند.
- مسیر `/health` نسخه `0.5.0` و `payment_enabled: false` برمی‌گرداند.
- تست بکاپ مجزا: نسخه پشتیبان SQLite و فایل آزمایشی در `store-documents/` با موفقیت ایجاد شد.
- بررسی نمای ایستا: دسکتاپ ۱۳۶۶ پیکسل، موبایل ۳۹۰ پیکسل، بدون اسکرول افقی کل صفحه.

محدودیت تست: استقرار اینترنتی واقعی، بارگذاری هم‌زمان، تست نفوذ تخصصی و استعلام مجوز انجام نشده‌اند. نمایش عکس‌های پنل از HTML واقعی سرور به روش رندر ایستا تهیه شد و به معنای تست کامل کلیک‌های مرورگر نیست.
