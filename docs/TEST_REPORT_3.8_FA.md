# نتیجه ممیزی و تست VARAQ ۳.۸

- فرمان: `npm test` روی Node.js 22.16.0 در محیط توسعه.
- **۱۲۳ تست: ۱۲۲ موفق، ۰ شکست، ۱ آزمون اجرا‌نشده.** آزمون اجرا‌نشده مربوط به نبود نسخه آرشیوی تاریخی ۱.۵ برای مهاجرت ۱.۶ است.
- ۵ آزمون اختصاصی ۳.۸: Open Graph/JSON-LD، ایندکس محافظه‌کار و سایت‌مپ، کش نام‌گذاری‌شده با هش و ETag/304، gzip عمومی و عدم فشرده‌سازی صفحات حساس، escape متادیتای کنترل‌نشده.
- تست ارتقای مستقل با اجرای واقعی نسخه ۳.۷ سپس ۳.۸ روی **همان `storage`**: ۲۰۰ کتاب، ۱۲۸ رکورد `edition_sources`، یک حساب مدیر و یک فروشگاه آزمایشی اضافه‌شده حفظ شدند؛ `PRAGMA integrity_check` برابر `ok`.
- آزمایش روی دامنه واقعی، Lighthouse/Core Web Vitals، Safari/Chrome/Firefox موبایل و اسکن امنیتی بیرونی **انجام نشده است**.
- ابزار `node preflight.js` هنوز انتشار تجاری را آماده نمی‌داند؛ کمبود اطلاعات و حقوق جلد و مدارک فروشگاه باقی است.
