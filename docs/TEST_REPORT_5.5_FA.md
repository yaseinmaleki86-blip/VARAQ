# گزارش تست VARAQ 5.5

- نسخه Node: نیازمند 22.13 یا بالاتر و ماژول داخلی `node:sqlite`.
- اجرا: `npm test`
- تعداد: ۱۷۶ آزمون، ۱۷۵ موفق، ۰ شکست، ۱ اجرا‌نشده.
- آزمون‌های ۵.۵: گزارش واقعی ۲۰۰ کتاب، فیلتر و صفحه‌بندی، CSV بی‌خطر در برابر فرمول، عدم تغییر دیتابیس توسط گزارش، مالکیت YM/محدودیت فروشنده، پیش‌پرشدن ISBN تأییدشده و جلوگیری از پارامتر ساختگی، حفظ قفل پرداخت.
- آزمون‌های قبلی ۵.۴: ثبت برگشت‌پذیر تصاویر، جلوگیری از ثبت تکراری، کنترل CSRF، احراز هویت.
- آزمایش مهاجرت: نخست اجرای نسخه ۵.۴ با دیتابیس و فروشگاه موجود، سپس اجرای ۵.۵ با همان داده‌ها، حفظ تعداد رکوردها و آزمون `PRAGMA integrity_check=ok`.
- مرورگر واقعی: اجرای Chromium با Playwright برای HTTP محلی در محیط فعلی با `ERR_BLOCKED_BY_ADMINISTRATOR` مسدود شد؛ هیچ نتیجه تست بصری ادعا نمی‌شود.
- تست واقعی درگاه پرداخت: انجام نشده؛ هیچ پرداخت یا تحویل پولی فعال نیست.
