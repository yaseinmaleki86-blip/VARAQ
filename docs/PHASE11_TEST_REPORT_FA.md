# گزارش تست نسخه 1.1

- `npm test`: ۳۱ تست موفق، صفر شکست (۲۶ تست قدیمی + ۵ تست جدید).
- آزمون CSV: شناسه واقعی، رد ردیف تکراری، ناموجود، خطای اعتبارسنجی، حفظ داده‌های قبلی، ثبت پیش‌نویس.
- آزمون تراکنش: ایجاد خطای عمدی هنگام درج دوم و بررسی بازگشت درج اول.
- آزمون مقایسه: فقط دو یا سه منبع منتشرشده، رد رکورد مخفی، شناسه تکراری، شناسه نامعتبر و بیش از سه انتخاب، خروجی امن HTML.
- آزمون دسترسی: مدیر YM، CSRF، تأیید اجباری ثبت و منع دسترسی فروشنده به ابزار CSV.
- آزمون محیط: تولید HTML سمت سرور با کتاب‌های نمونه و رندر ایستا در Chromium برای ۱۴۴۰ و ۳۹۰ پیکسل؛ بدون بیرون‌زدگی افقی در صفحه‌های آموزشی/مقایسه.
- محدودیت: تعامل مرورگر مستقیم با `localhost` توسط محیط مسدود بود. تست‌های API/HTTP در Node اجرا شدند؛ استقرار عمومی و بررسی موبایل واقعی باقی است.
- در هیچ آزمونی پرداخت اینترنتی فعال نشد.
