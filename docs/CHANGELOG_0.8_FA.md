# VARAQ 0.8 — فاز هشتم | ۱۴۰۵/۰۸/۰۹

## تغییرات

1. داشبورد گزارش آزمایشی با فیلتر بازه تاریخ UTC، وضعیت سفارش و فروشگاه.
2. مقایسه مبلغ و تعداد سفارش‌های نمونهٔ فروشگاه‌ها در سطح مدیریت YM.
3. پنل نرخ فرضی کارمزد هر فروشگاه به‌صورت basis points (عدد صحیح) با دقت ۰.۰۱٪، فقط توسط مدیر YM.
4. تاریخچه تغییرات نرخ همراه شناسه کاربر تغییر‌دهنده.
5. محاسبه و ثبت پایدار سهم فرضی فروشنده و YM در همان تراکنش ثبت سفارش نمونه.
6. عدم بازنویسی تاریخی سفارش‌های نسخه 0.7؛ تمایز سفارش‌های بدون عکس نرخ.
7. CSV فیلترشده با جداسازی دسترسی فروشندگان و پیشگیری از formula injection.
8. نمودار روند روزانه با HTML progress (بدون inline style و سازگار با CSP).
9. ارتقای تدریجی SQLite بدون حذف حساب‌ها، کتاب‌ها، فروشگاه‌ها، تصاویر، سفارش‌ها و انبارهای قبلی.

## محدودیت

تمامی مقادیر به تومان و صرفاً نمونه هستند. هیچ پردازش پرداخت، صورتحساب واقعی، تسویه، محاسبه مالیات یا دریافت وجه وجود ندارد. لازم است منطق سفارش واقعی و پرداخت رسمی با مجوز، قرارداد و ممیزی مستقل طراحی و تست شود.
