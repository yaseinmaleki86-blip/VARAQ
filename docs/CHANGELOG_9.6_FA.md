# ورق — بسته یکپارچه محلی ۹.۶

## چه چیزی واقعاً اضافه شد؟

- یک مبدأ وب محلی: آدرس اصلی `http://127.0.0.1:3030/` و فروشگاه `http://127.0.0.1:3030/market/` با **همان میزبان و پورت**.
- مسیریابی داخلی امن Node → Python فقط برای `/market/`، بدون پراکسی عمومی یا وابستگی جدید.
- ورود مشترک برای **مدیر مرکزی و فروشنده دارای اختیار مدیر فروشگاه** از طریق امضای کوتاه‌عمر HMAC. رمز اصلی کاربر نه کپی و نه در شبکه مرورگر ارسال می‌شود.
- پس از خروج از حساب پنل اصلی، دسترسی مدیریتی فروشگاه هم در درخواست بعدی قطع می‌شود. کاربران دارای رمز اولیه تعویض‌نشده حق اتصال مدیریتی ندارند.
- سطح دسترسی فروشنده بر اساس نگاشت مستقل فروشگاه کنترل می‌شود؛ مالکیت فروشگاه‌های موجود جابه‌جا نمی‌شود.
- لینک «فروشگاه و خرید» و سبد خرید مشترک در ناوبری مرجع، لینک بین صفحه معرفی کتاب و صفحه همان عنوان در فروشگاه، اصلاح لینک‌های داخلی/تصاویر/فرم‌ها و مسیر کوکی.
- شروع دو سرور با `START_UNIFIED_WINDOWS.bat` یا `START_UNIFIED_LINUX_MAC.sh`؛ کلید پل ورود برای هر اجرا در حافظه ساخته می‌شود.
- ۱۰۰۰ کتاب و ۲۰۰۰ فایل تصویر WebP موجود بدون حذف، جایگزینی یا کپی دوباره.

## هنوز چه چیزی ادغام نشده؟

- دیتابیس تحریریه و فروشگاه دو SQLite مستقل‌اند؛ قیمت‌ها، موجودی‌ها، سفارش‌های آزمایشی قدیمی Node و سفارش‌های Python **تاریخچه مشترک ندارند**.
- مشتریان در آدرس `/market/register` حساب می‌سازند. ورود یکپارچه مدیر/فروشنده به معنی انتقال خودکار حساب‌های مشتری یا سفارش‌های قدیمی نیست.
- پرداخت واقعی، درگاه فروشنده، حقوق PDF، اجرای روی هاست عمومی و آزمون خرید واقعی تأیید نشده‌اند.
- جلدهای مفهومی ۸.۶ معادل تصویر رسمی ناشر نیستند. قیمت/موجودی غیرتأییدشده صفر است.
- این بسته برای آزمایش محلی است؛ انتشار اینترنتی یا دریافت پول مجاز نیست.

## نصب و حفظ اطلاعات

1. **از نصب قبلی با `BACKUP_WINDOWS.bat` و ابزار بکاپ فروشگاه نسخه ۹.۵ پشتیبان بگیرید.**
2. نسخه ۹.۵ را حذف نکنید؛ این بسته را در پوشه‌ای **جداگانه** استخراج کنید. تغییرات روی نصب قبلی انجام نمی‌شود.
3. فایل `START_UNIFIED_WINDOWS.bat` را اجرا کنید (Node.js 22.13+ و Python 3.10+).
4. ابتدا در پنل مرجع `/login` با حساب مجاز وارد شوید و رمز اولیه را تغییر دهید. سپس `/market/admin` یا `/market/seller` را باز کنید.
5. مشتریان برای خرید آزمایشی از `/market/register` استفاده می‌کنند. ورود اطلاعات واقعی مشتری یا دریافت پول تا ممیزی حقوقی/امنیتی توصیه نمی‌شود.
6. بستن پنجره شروع یکپارچه، پایان فرآیندها را درخواست می‌کند. برای توقف از `STOP_UNIFIED_WINDOWS.bat` هم می‌توان استفاده کرد.

**هشدار:** این بسته داده‌های ذخیره‌شده جدیدِ حساب‌ها و سفارش‌های نصب قبلی را به‌طور خودکار وارد نمی‌کند. آن را به‌عنوان ارتقای درجا روی دیتابیس فعال نصب نکنید؛ از پشتیبان و راهنمای مهاجرت استفاده کنید.

## آزمون‌ها

- ۱۸ تست یکپارچگی HTTP: مسیرها، جلد، هویت جعلی، CSRF، تغییر رمز اولیه، ورود یکپارچه و خروج.
- ۷ کنترل امنیتی و تفکیک فروشنده در تست اختصاصی.
- ۴ مجموعه رگرسیون Python: سبد، پرداخت تأییدنشده، PDF، موجودی، کاتالوگ و تراکنش.
- ۱۱ تست Node منتخب برای بانک ۱۰۰۰ کتاب، تصاویر و مسیرهای مرجع.
- تست‌های کامل ۲۰۰+ سناریوی قدیمی و انتشار در زیرساخت واقعی اجرا نشده‌اند.
